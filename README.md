## 📌 Proje Hakkında

**Özgür Mağaza**, kullanıcıların özgürce alışveriş yapabileceği, modern ve kullanıcı dostu bir e-ticaret arayüzü/altyapısı sunmayı hedefleyen açık kaynaklı bir projedir. Bu proje; hız, sade tasarım ve kolay özelleştirilebilirlik odaklı geliştirilmiştir.

---

## 🚀 Özellikler

- 📱 **Responsive Tasarım:** Mobil, tablet ve masaüstü cihazlarla tam uyumlu arayüz.
- ⚡ **Hızlı ve Hafif:** Gereksiz şişkinliklerden arındırılmış optimize edilmiş yapı.
- 🛍️ **Ürün Yönetimi & Listeleme:** Ürünleri kategorize etme ve detaylı görüntüleme.
- 🔒 **Güvenli Altyapı:** Güncel web güvenliği standartlarına uygunluk.

---

## ⚙️ Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları takip edebilirsiniz:

1. **Depoyu klonlayın:**
   git clone https://github.com/yahya3886/ozgur-magaza.git

2. **Proje dizinine gidin:**
   cd ozgur-magaza

3. **Çalıştırın:**
   - Statik dosyalar için doğrudan `index.html` dosyasını tarayıcınızda açabilir ya da Live Server kullanabilirsiniz.
